# Habitat suitability, step selection, and connectivity of Asiatic black bears on Shikoku

Analysis scripts associated with a *Biological Conservation* manuscript revision. The repository covers the landscape-scale RSF, final 100-m integrated step-selection functions (iSSF), validation, and connectivity simulations.

**Sensitive data are not public.** The original bear GPS locations, confirmed-range boundary, and analysis rasters are excluded because of conservation sensitivity and restrictions on data sharing. This repository contains source code and documentation, **not** the restricted data or derived spatial outputs.

## Repository structure

```text
R/
  00_config.R                   Shared paths
  01_prepare_landscape.R        RSF zones, forest sample, focal scales
  02_fit_predict_rsf.R          RSF model comparison, mapping and core patches
  03_figure4_coefficients.R     Manuscript Figure 4
  04_figure5_covariates.R       Manuscript Figure 5
  10_issf_common.R              17-term iSSF formula, data QC, IVW pooling
  11_fit_issf.R                 Fit tracks, individuals and population models
  12_validate_issf.R            LOIO simulation validation
  13_figure6_logrss.R           Manuscript Figure 6
  14_resolution_sensitivity.R   Optional 10/50/100/200-m comparison
  20_simulation_functions.R     Candidate steps, environment extraction, iSSF weights
  21_run_connectivity.R        Final sex-season connectivity simulations
```

Only manuscript Figures **4, 5 and 6** are generated by the code. Other paper and supplementary figure-generation scripts are intentionally not included. The RSF core patch rasters and simulation visit-count rasters are **analytical products**, not figure panels.

## Installation and execution

Run from the repository root with R (4.2+ recommended). Suggested packages:

```r
install.packages(c("terra", "sf", "dplyr", "tidyr", "car", "survival", "ggplot2", "patchwork"))
```

The default repository root is the current working directory. To use another root, set the `SHIKOKU_PROJECT_ROOT` environment variable, or run R from this folder. All outputs are placed below `results/`, which is Git-ignored.

Run the components in sequence, using the authorized, pre-existing data:

```bash
# Landscape-scale RSF
Rscript R/01_prepare_landscape.R
Rscript R/02_fit_predict_rsf.R
Rscript R/03_figure4_coefficients.R
Rscript R/04_figure5_covariates.R

# Final 100-m iSSF
Rscript R/11_fit_issf.R
Rscript R/12_validate_issf.R
Rscript R/13_figure6_logrss.R
Rscript R/14_resolution_sensitivity.R   # optional; missing resolutions are reported

# Connectivity: test before the full, computationally demanding run
Rscript R/21_run_connectivity.R --smoke-only
Rscript R/21_run_connectivity.R
```

Scripts `10_issf_common.R` and `20_simulation_functions.R` are sourced by the scripts that need them; they are not stand-alone workflows.

## Methods encoded in the scripts

### Landscape-scale RSF

- A = confirmed bear-occurrence MCP; B = 0–8.9 km uncertainty buffer (excluded from model fitting); C = 8.9–17.8 km outer comparison ring.
- Analysis grid: 100 m, EPSG:32653. Forest-dominated eligibility requires forest proportion ≥ 0.5; balanced sample of 10,000 A and 10,000 C cells.
- Focal-scale candidates: 25, 50, 100, 150, 250, 500, 1,000, 2,000, 4,000 m. Focal rasters must already have been calculated from native layers.
- Four-fold spatial k-means CV; model covariates include built-up proportion, linear/quadratic deciduous broadleaf forest, and log-transformed distances to main/minor roads. Candidate models with VRM and forest-edge terms are compared and diagnosed, but the manuscript model is fixed to the verified final base formula.
- Full-Shikoku prediction is a **relative landscape suitability index**, not an absolute occurrence probability. Ten equal-area bins are calibrated in A+B+C and applied island-wide. Bins 8–10 are suitable; 8-neighbor patches ≥93.1 km² are core habitat.

### Final iSSF

- Requires the **already preprocessed and filtered 100-m used/available step dataset**. The 1-h (±10-min) resampling, 20-m post-step filtering, generation of ten available steps, track exclusions, focal-scale search and original raster extraction are **not reconstructed** by this code release. They must be completed according to the manuscript before running these scripts.
- The input is expected to contain 41 retained seasonal tracks with 80+ observed steps, comprising 21 sex-season individual memberships across four categories (the same bear can contribute to multiple seasons). The strict code checks group-level counts; it does not treat group memberships as unique bears across seasons.
- 17-term iSSF, conditional logistic regression with one observed + ten available steps per stratum. Models are fitted by seasonal track and pooled first within individual and then across individuals using term-wise inverse-variance weights; off-diagonal covariance is propagated for Figure 6.
- Leave-one-individual-out evaluation (held out at `real_id` level) uses 200 movement simulations per held-out track and 999 spatial-null iterations. This implementation should be **numerically compared with the original private LOIO outputs** before being used to assert exact reproduction, particularly the area-adjusted rank-correlation convention.
- Optional raster-resolution sensitivity requires matching step-choice tables preprocessed at 10, 50 and 200 m. Missing resolution datasets are skipped, never imputed.

**Expected final 100-m sample counts (strict QC):**

|---|---|---:|---:|---:|

| Female | Mating | 7 | 10 | 5,261 |
| Male | Hyperphagia | 5 | 10 | 3,398 |

### Connectivity simulations

- Start domain: RSF core suitable habitat (bins 8–10, 8-neighbor patch ≥93.1 km²) intersected with the confirmed-occurrence MCP and valid 100-m iSSF covariate coverage.
- Uses **the new RSF core**, not earlier legacy core raster definitions or old trajectories. The script checks four core patches, one occupied patch and three target patches, and the previously established core area and occupied overlap.
- Four groups (female/male × mating/hyperphagia), 1,000 trajectories each, 11 empirical candidate movements per step. Endpoints are selected by the 17-term population iSSF linear predictor using numerically stable normalized weights.
- Mating horizons: 378, 756 and 1,512 steps. Hyperphagia horizons: 355, 710 and 1,420 steps. Simulate once at the longest horizon, then truncate for 1× and 2× summaries.
- Outputs are one restricted RDS per trajectory, target-patch arrival summaries, QC and primary-horizon visit-count rasters. **No figure-generation code** is run.
- `--smoke-only` checks one short sequential trajectory per group and stops before full simulation. The full run performs the same smoke tests, saves a simulation-configuration manifest and supports safe resumption when parameters match.

## Reproducibility caveats

The RSF scripts were cleaned from the supplied original scripts. The final iSSF and connectivity code reflect the checked model formula, QC counts and simulation design, but were assembled from the available prior scripts and documented inputs rather than copied verbatim from every private analysis stage. The iSSF preprocessing pipeline and exact legacy LOIO metric implementation are not independently reconstructible from the inputs available here.

**This package has not been run on the restricted data**, and the runtime used to package it does not have an R interpreter. Source structure and delimiters can be checked, but full R parsing, package behavior and numerical reproduction still require a local smoke test and comparisons with the original output tables. Do not claim exact numerical reproducibility until these comparisons pass. In particular, check the raw signed forest-edge treatment in Figure 5 against the final plotted data and manuscript caption.
